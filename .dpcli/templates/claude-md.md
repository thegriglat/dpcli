## Процесс работы с агентами (dpcli)

Процесс, роли, контракты, правила, типы агентов, наблюдение — **`{{workflow}}`** (прочитать перед любой многошаговой работой). Журнал, задания, ветки, документы — `{{cli}}` (справка `{{cli}} -h`, `.dpcli/README.md`).

Коротко:
- Роли: пользователь — решения; главная сессия — глобальный координатор (планы, координаторы модулей, отчёт каждые 30 мин, слияния в `{{main_branch}}` по одобрению); координатор модуля (`dp-coordinator`) — план, **контракты до исполнителей**, копия на задачу, приёмка (`{{cli}} accept`, ревью по риску — `dp-reviewer`), шлюзы, сам не ревьюит; исполнители — одна задача в своей копии.
- Детерминированное — командами `{{cli}}`, а не своими скриптами; журнал (`{{plan_dir}}/<модуль>/`) только дописывается командами.
- Корректность прежде «нравится»; не шлифовать; не выдумывать — числа из замеров.
- Долгие запуски — фоном или `{{cli}} job start/wait`; не `pgrep -f`/`pkill -f`.
- Коммиты — только свои файлы (`git commit -- <пути>`), по-русски, со строкой Claude-Session; не пушить без команды пользователя.
- Документация: точка входа `INDEX.md` каталога документов; «что мы знаем про X» — `{{cli}} docs findings X` / `{{cli}} docs find`; frontmatter обязателен, `{{cli}} docs check` перед коммитом документов.
- Агенты правятся в `.dpcli/agents/`, процесс — в `.dpcli/templates/workflow.md`; `.claude/` перегенерирует `{{cli}} init`.
